# ButtonGraphicImage

> Current Version: `v1.0.1`  
> [Launch in Widgetbook ↗](https://theoreticallydark.github.io/alter/#/buttons/buttongraphicimage)

## Overview
`ButtonGraphicImage` is a compact `48x48` image/avatar action button featuring rounded corners (`20px`) and `AlterSemanticTokens.ui1` background fill.

## Usage
```dart
ButtonGraphicImage(
  onTap: () => print('Avatar tapped'),
)
```

## Properties
| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `onTap` | `VoidCallback?` | `null` | Tap callback handler. |
